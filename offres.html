Gratuit ou Premium

Dans ce prototype, toutes les fonctionnalités restent accessibles pour la démonstration. Voici comment un vrai lancement pourrait répartir le contenu.

Gratuit

0 FCFA

  • Une sélection de cours de code de la route

Accessible dès l’inscription

Premium

À définir

  • Tous les cours et toutes les vidéos

  • Accès à tous les simulateurs

Aucun paiement réel n’est intégré à ce prototype. Une mise en production nécessiterait un prestataire de paiement local sécurisé (ex. Orange Money, Wave, carte bancaire) et une configuration conforme aux exigences de sécurité et de conformité applicables au Sénégal.
