# Backend SunuPermis

Le backend actuellement maintenu est l’API Express dont le point d’entrée est `server/index.js`. Il se lance depuis la racine du dépôt avec `npm start` et écoute sur le port défini par `PORT` (3000 par défaut).

La configuration requise, les routes, les commandes de test et les consignes de sécurité sont documentées dans le [README principal](../README.md). L’ancien serveur Node natif décrit dans des versions précédentes n’est pas présent dans ce dépôt et ne doit plus être utilisé.
